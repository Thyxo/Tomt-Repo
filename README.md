# Autoclicker (AutoHotkey v2)

1. Installer **AutoHotkey v2** fra https://www.autohotkey.com
2. Download `autoclicker.ahk` og dobbeltklik på den.
3. Slå "Venstre klik" eller "Højre klik" til (F6 / F7) og hold museknappen nede.

| Tast | Funktion |
|---|---|
| F6 / F7 | Venstre / højre klikker til/fra |
| Insert | Vis/skjul vinduet |
| F8 | Panik – stop alt |
| F9 | Luk programmet |

Alle taster kan ændres under **Keybinds** (også Mus 4/5).
Indstillinger gemmes i `autoclicker.ini`, configs i mappen `configs`.
